1. 项目最终目标
======================================================================

这个项目不是单一神经网络仓库，而是一条从数据到机器人执行的完整多阶段抓取链。

最终目标是：

1. Isaac Sim 5.0 / Isaac Lab 2.2加载双臂机械臂、右侧Wuji2 Hand 2、大桌面、
   蓝色抓取区、绿色放置区和顶部RGB-D相机；
2. 相机对蓝区拍摄一张RGB-D；
3. 用户在终端输入要抓的物体，例如dog、ashtray或hammer；
4. GroundingDINO + SAM根据文本找出目标像素掩码；
5. 深度、内参、外参转换成完整场景单视角40000点，目标物体点只作成员标记，
   不能把孤立目标点云代替完整场景输入；
6. DexGraspNet 2.0对完整场景生成1024条抓取候选；
7. 只在属于目标物体的候选中排序，再做场景、桌面、PREGRASP和路径过滤；
8. 若使用官方LEAP网络输出，则通过官方wuji-retargeting迁移成Wuji2 q20，
   再独立求Wuji2手根6D；若使用自训练Wuji2网络，则直接使用网络q20；
9. 右机械臂IK把固连的Wuji2手带到PREGRASP、GRASP和SQUEEZE；
10. 抓起目标，移动到绿色放置区，下降、松手、退让并回到初始姿态；
11. 终端持续显示当前状态，完成后可以继续询问下一个抓取目标。

当前已经跑通的不是全部实时循环，而是这一目标的一个重要子集：

- 正式测试集scene_0000经重力落稳、顶部相机重拍；
- 缓存的RGB-D、GroundedSAM、官方LEAP网络结果；
- dog候选3800；
- LEAP到Wuji2迁移；
- 右臂IK；
- Isaac Lab完整抓、搬、放和回程。

当前完整抓放物理动作仿真时间为24.85 s，但在本机120 Hz GUI物理计算的现实耗时
约272.98 s。报告演示入口使用缓存的视觉/网络结果，物理抓取会重新运行；它不是
“每次现场重新拍照并重新执行所有神经网络”的最终连续循环。

2. 三条必须严格分开的技术路线
======================================================================

路线A：Wuji2数据集与自训练20关节网络
--------------------------------------------------

Wuji2 1.0单物体抓取数据
-> 多物体稳定场景和单视角点云
-> 场景碰撞与路径过滤
-> graspness/单视角标签
-> Wuji2 20关节DexGraspNet2训练
-> 单视角1024候选
-> 原生Wuji2抓取动作
-> 3P+3R手根仿真验证

路线B：官方DexGraspNet2 LEAP输出迁移到Wuji2
--------------------------------------------------

官方LEAP q16和LEAP手根6D
-> LEAP FK得到MediaPipe 21点
-> 官方wuji-retargeting得到Wuji2 q20
-> 四个对应指尖Kabsch求Wuji2手根6D
-> 官方LEAP SQUEEZE迁移成Wuji2 SQUEEZE
-> 3P+3R手根仿真验证

路线C：双臂机械臂完整系统
--------------------------------------------------

桌面/区域/相机/双臂场景
-> RGB-D与文本分割
-> 路线B目前成功的抓取姿态
-> 法兰到Wuji2手腕固定装配变换
-> 右臂7关节IK与路径碰撞检查
-> 完整抓取、搬运、放置、松手、回初始姿态

整理时绝对不能把路线A和路线B的SQUEEZE、PREGRASP或根坐标合同混为一套。
路线C可以消费A或B的结果，但目前正式成功案例主要来自路线B。

- SQUEEZE也从官方LEAP SQUEEZE重新迁移；

- 手根使用LEAP同构的3P+3R Force位置驱动，K800、D20；
- 手指服从官方Wuji2 USD；
- 成功标准目标质心上升至少30 mm。
